## Introduction
Factorio is a 2d factory planning game, where the player is placed on an empty planet with resources, and is tasked with building a factory to eventually build a rocket ship to escape the planet and beat the game. To build the rocket the factory must produce resources of many types, such as iron, steel, gears, circuit boards and many more, which can then be used to produce more advanced resources. Overall, the factory consists of buildings, which have fixed input resources, output resources and connected throughput rates, and conveyor belts which transport between buildings. The challenge lays in planning ahead, managing the supply and demand between the various types of resources, eliminating bottlenecks and structuring the factory in a scalable manner. The goal is to first abstract the core mechanics into a model that is sufficiently close to the game, but to remove aspects which are difficult to model and significantly increase the decision space such as building placement and conveyor belt routing. After the game has been sufficiently modeled, we can then utilize the model of the game to explore the optimal path forward to achieve some set sub-goal given an existing game instance that has been played up to a set timestep.

## Running the model
- To run the model, we must use the right conda environment, for example using `conda activate aspproj`
- Then, to run the model with an instance (limit memory to MAX 128GB, no swap, max 32 threads, since there is a running ML training job): `systemd-run --user --scope -p MemoryMax=128G -p MemoryHigh=120G -p MemorySwapMax=0 clingcon model.lp instances/testinstance.lp --opt-mode=opt --quiet=1 -t 32 --time SECONDS`
